# Permission boundaries

**Fact or rule:** Ask before deleting, renaming, or moving project files; installing packages or plugins; Git commit, push, rebase, or reset; unrelated changes to `project.godot`, `.gitignore`, or export settings; reading or editing outside this project; or replacing a major system. Do not discard uncommitted work or inspect unrelated personal files.

**Why:** The user wants control over irreversible work and project scope.

**How to apply:** Continue with authorized edits and tests inside this project. Explain sandbox blockers and ask before running outside the sandbox. Keep durable notes in `memory/`, update existing topic notes, and ask before deleting a note.
